# OBBETA006–010 — owner dashboard readiness classification

Parent: `main@86bd111ee045866cb847dc2678c52f26c8f19854` (accepted OBBETA001–005). That is an operator-confidence/rehearsal source, not independently authenticated Tower owner permission, broker options or settlement truth, or production approval.

The owner dashboard now shows **OWNER REHEARSAL · LIVE HOLD** and constant **Owner rehearsal evidence · Real Manual Live HOLD**, retaining the existing numeric score solely as practice-context evidence. It explicitly distinguishes `operator_practice_only_not_tower_or_provider`; Tower owner clearance, authenticated broker source and production Manual Live permission are false. Attention copy points to a rehearsal checklist, and blocker text notes external Tower/provider gates remain pending. It does not read or fabricate a Tower token or receipt. Normal-user Dashboard remains Survey/Paper, owner-only capital views stay owner-only and Live Auto remains locked.

The existing `sourceLooksVerified` heuristic is not a cryptographic verifier; this patch does not promote its results into Tower or external/provider authority. OBML016–020's source namespace correlation remains non-authorizing. True external gates still require Tower draft #68 implementation, secure OB receiver, hosted observation, provider/account/settlement evidence, protected floors, owner Review Center decision, later independently reconciled human brokerage action and independent operating/security/compliance approval.

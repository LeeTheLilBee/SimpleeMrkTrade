
# OBUX091–095 — Dual Dashboard Clean-Slate Replacement

## Product decision

The Observatory now has two deliberately different Dashboard experiences.

### Normal User Dashboard

The normal Dashboard is a calm self-directed market home.

It supports:

- Survey
- Paper
- general market awareness
- neutral symbol exploration
- paper practice
- review / session context
- Soulaana explanation

It does not receive:

- Owner Capital Lanes
- owner-ranked candidate payloads
- individualized live security recommendations
- option-contract recommendations
- owner Manual Live recommendation intelligence
- broker submission
- capital movement
- automatic contract selection
- automatic execution

### Owner Dashboard

The Owner Dashboard is the premium Observatory intelligence cockpit.

Primary hierarchy:

1. Soulaana owner briefing
2. Today's Edge
   - NOW
   - WATCH
   - NOT YET
3. compact market / position / alert context
4. top-three owner attention
5. progressively disclosed owner intelligence

Capital Lanes remain owner-only but are secondary context.

## ADHD design requirements

- one dominant focus
- maximum three primary attention cards
- no default list wall
- no default table wall
- no six-equal-card information dump
- short answer first
- drawers for detail
- one drawer at a time
- evidence only on demand
- keyboard focus
- Escape closes drawers
- reduced-motion support

## Candidate truth

Owner research consumes the existing canonical engine web projection.

A candidate may appear in NOW only when:

- the canonical engine projection is current eligible
- display eligible
- fresh
- source candidate state supports a NOW-like state

Otherwise it falls to WATCH or NOT YET.

The Dashboard does not manufacture a NOW state.

## Options

Existing options research may be displayed.

Ranked contract research remains research.

Selection authority remains OWNER.

OB does not silently convert ranking into a selected contract.

## Locked execution boundaries

- broker submission: disabled
- capital movement: disabled
- automatic contract selection: disabled
- automatic execution: disabled
- Live Auto: locked

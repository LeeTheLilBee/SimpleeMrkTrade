# OBUX051–055 — Canonical Owner Console

## Base

`a5e4fe0ba95d5eec04bc6bdbb58e39b185f5f0e0`

## Purpose

Replace the V17 hardcoded Owner Console surface with a source-backed owner deck.

The room answers four questions:

1. Is OB healthy?
2. Is owner capital protected by the current operating boundaries?
3. What needs owner attention?
4. What is locked, degraded, guarded, stale, missing, or unknown?

## OBUX051 — Canonical Owner Deck

The primary owner-facing layout is:

- four-question status strip
- attention queue
- Observatory system-health hero
- Soulaana explanation
- mission-account policy panel
- engine/source truth panel
- canonical room-chain health
- hard safety lock wall
- progressive source-detail drawer

The old six-tab list interface is removed from the primary experience.

## OBUX052 — System Truth Projection

Owner Console projects existing truth from:

- Engine Feed Diagnostics V33
- Engine Trust Labels V34
- Engine Room Mapping V35
- Owner Source Audit V36
- Review Center canonical projection
- existing readiness layers
- existing mission-account session state

Owner Console does not create another market-data, diagnostics, readiness, review, or mission-account engine.

## Fallback doctrine

Fallback is allowed only as explicitly labeled fallback truth from the existing diagnostic system.

Owner Console does not transform fallback into healthy.

Unknown stays unknown.

## Mission accounts

Mission-account policy metadata remains visible.

No balance, available capital, risk utilization, realized P&L, or account health is invented.

Those fields remain unavailable until canonical account-level financial truth exists.

## Owner attention

Owner attention may be generated from source-backed facts such as:

- degraded/guarded diagnostics
- missing/stale/fallback-only source audit
- unresolved Review Center attention
- readiness blockers
- guarded/degraded room mapping

## Safety

Owner Console is read-only.

It cannot:

- read broker accounts
- execute broker orders
- auto close a position
- auto execute
- automatically select a contract
- unlock Live Auto

## Tower

This build does not modify Tower files.

# OB Hybrid Readiness Gate

## Locked progression

The Observatory progression is now:

1. Three simulation accounts using real-market evidence
   - CONTROL
   - INTEGRATED
   - EXPERIMENTAL
2. Hybrid Readiness Gate
3. Tower clearance
4. Explicit owner approval
5. Owner-approved Hybrid pilot
6. Broader Hybrid only after live receipts support it
7. Automated Live remains a later, separately earned state

Manual Live L1 is no longer required as the primary proving period. It remains available as a fallback/recovery operating mode.

## What Hybrid means

Hybrid means OB and Soulaana may discover, research, interpret, construct, and prepare a proposed order. The owner must approve or reject before any live broker submission.

Hybrid does not mean autonomous trading.

## Gate doctrine

Profit does not open the gate.

The gate opens for review only when the system demonstrates trustworthy behavior across data integrity, point-in-time evidence, Soulaana interpretation, simulation realism, risk controls, bad-data handling, lane isolation, auditability, broker-path rehearsal, explainability, evidence volume, and critical-failure clearance.

A passed gate returns:

QUALIFIED_FOR_OWNER_APPROVED_HYBRID_REVIEW

That result does not unlock Hybrid. Tower clearance and explicit owner approval remain separate required steps.

## Required checks

- Real source-backed market data
- No future-data leakage
- Source receipts/provenance
- Soulaana actually received relevant inputs
- Soulaana produced useful interpretation
- Realistic fills/spreads/slippage
- Correct options contract identity when options are used
- Risk controls passed
- Bad/stale/conflicting data causes HOLD/degraded behavior
- Three simulation accounts remain isolated
- Full audit trail
- Hybrid broker path rehearsed end-to-end
- No unresolved unexplained decisions
- Enough evidence across different market conditions
- Zero unresolved critical failures during qualification

## Safety boundary

The gate itself can never:
- unlock Hybrid,
- submit a broker order,
- move capital,
- waive Tower clearance,
- waive owner approval,
- unlock Automated Live.

# OBSIM036–040 — explicit historical/synthetic owner rehearsal input desk

Stacked on reconciled source-only owner simulation [PR #50](https://github.com/LeeTheLilBee/SimpleeMrkTrade/pull/50), after accepted [PR #88](https://github.com/LeeTheLilBee/SimpleeMrkTrade/pull/88) local archive read/final-chain verification. **Not a hosted or live owner beta release.**

This source-only bridge lets a future protected local owner interface call the accepted session with one explicit canonical input at a time. It does not create a second replay/price/policy engine: it constructs OBTIME through `build_market_schedule` and `build_canonical_market_time`, frames/instruments through canonical OBSIM builders, and three owner-authored `ReplayDecision` objects. The existing `tick_session` still owns cadence, source-age checks, fresh history replay, CAPSIM and immutable private archive persistence. A 30-second due hint never fetches data, creates a decision or queues an unattended tick.

**Strict input contract:** `OBSIM_EXPLICIT_OWNER_REHEARSAL_INPUT_V1` accepts exactly schema/source kind/account/frame/calendar/three lane decisions; every market mark, source reference, observed time, calendar session boundary, strategy and reason must be explicit. The account must exactly match the in-process harness. No unknown permission/broker flags, fake verified source, invalid price, nonfinite numbers, naive timestamps or cross-account scope. Historical/Synthetic **only**. An owner-declared calendar is not externally authenticated; `OWNER_DECLARED_` is mandatory. An Experimental OPEN/CLOSE cannot be silently admitted without the separate CAPSIM policy source, so this local bridge refuses it. No default trade selection or auto winner.

**Controller:** `LocalOwnerRehearsalDesk` exposes in-process `view`, `submit_explicit_input`, `pause`, `resume`, `stop`. It only changes its immutable session after the established `tick_session` persists successfully. The stop result is verified report-only archive status, not an in-memory live-trading restoration. All API views explicitly deny independent provider/Tower authentication, automatic timer, broker, capital, Manual Live, Hybrid or Auto grants.

**Acceptance:** focused tests cover real OBTIME builder output, due interval and pause/resume, archive finalization, exact three lane decisions, wrong account/schema/extra authentication flag denial, fake/invalid numeric and time data, Experimental bypass and no capabilities; run exact-head full OB repository regression.

**Remaining external work:** connect this bounded in-process adapter to a genuine protected active local owner surface and approved owner-input capture; exercise on-device storage and Tower→OB owner navigation with actual hosted revision. Independently authenticated financial broker/market inputs and real trading authorization are separate future gates. This PR neither provisions a server/paid resource nor makes PR #50 production-ready. No broker API or unattended scheduler.
